---

### 🌟 BỘ TOOL AI TOP 1 THẾ GIỚI ĐƯỢC TÍCH HỢP SẴN:

1. **🤖 Cline (Autonomous Coding Agent):**
   - Agent AI tự hành số 1 thế giới trong VS Code hiện nay.
   - Tự động đọc file, viết code, tạo component, sửa lỗi và xem trước giao diện.
   - Hỗ trợ cắm API: **DeepSeek (V3/R1)**, **Claude 3.5 Sonnet**, **Gemini 2.0 Flash/Pro**, **OpenAI**.
2. **🦘 Roo Code (Roo-Cline):**
   - Bản mở rộng cao cấp của Cline chuyên biệt hóa chế độ **UI / Frontend Mode**.
3. **⚡ Continue.dev & Copilot:**
   - Trợ lý gợi ý code thời gian thực, autocomplete và inline chat.
4. **🎨 Hệ Sinh Thái Frontend Chuẩn Quốc Tế:**
   - Node.js 22 LTS (64-bit), PNPM, Vite, Next.js 15, Tailwind CSS, shadcn/ui.
   - Tự động mở màn hình xem trước (Live Preview / Port 3000 & 5173) khi anh chạy web!
